# 保羅的小島

我的第一個網站類型練習專案：一個代表保羅的小人偶住在島上。

## 怎麼打開

直接用瀏覽器打開 `index.html`（雙擊檔案即可），不需要安裝任何東西。

## 功能

- 點擊島上任何地方：保羅會走過去
- 鍵盤方向鍵：讓保羅上下左右移動
- 點擊保羅：他會跟你打招呼
- 點到海上：保羅會說他不會游泳
- **工作室**：保羅走到工作室門口，可以借 10 種工具（木工、電工、電路板焊接、數位製造），一次借一樣，用完要還
- **家**：保羅走到家門口，可以吃巧克力

## 技術

單一檔案 `index.html`，只用 HTML + CSS + JavaScript（SVG 繪圖），沒有任何外部套件。
